# 单词听写小程序 PRD（移动端优化版）

---

# 一、产品目标（明确收敛）

## 1.1 核心目标
打造一个可以“随时来一局”的移动端英语听写工具，让用户在碎片时间完成高频训练。

## 1.2 成功标准
- 7日留存 > 25%
- 人均单次学习时长 > 3分钟
- 每日启动次数 ≥ 2

---

# 二、核心设计原则（移动优先）

## 2.1 单手操作（One-thumb UX）
所有核心操作必须在屏幕下半区完成。

## 2.2 自动流 + 可打断
- 默认自动推进
- 用户随时点击可跳过/继续

## 2.3 极短路径
打开 → 1秒内进入听写

## 2.4 高频反馈
每2~3秒必须有一次反馈（视觉/音效/数值）

---

# 三、核心流程

首页 → 听写 → 结果 → 再来一局

支持：中断恢复

---

# 四、页面与交互稿

## 4.1 首页（任务驱动）

### 结构

```
┌────────────────────┐
│ 👋 欢迎回来         │
├────────────────────┤
│ 🎯 今日任务        │
│ 30 / 50           │
│ [继续学习]        │
├────────────────────┤
│ ⚡ 快速开始        │
│ [5个单词] [10个]  │
├────────────────────┤
│ 📊 数据            │
│ streak: 5天        │
└────────────────────┘
```

### 关键交互
- 默认高亮「继续学习」
- 支持一键快速开始

---

## 4.2 听写页（核心）

### 交互稿

```
┌────────────────────┐
│ ← 12/50        ⏸  │
├────────────────────┤
│                    │
│      🎧 播放中     │
│   （点击任意区域） │
│        重播        │
│                    │
├────────────────────┤
│  apple             │
│                    │
│  🔊 重播   ⌫ 删除  │
└────────────────────┘
```

---

### 核心交互逻辑

#### 1. 播放逻辑
- 进入自动播放
- 3秒未输入自动重播
- 点击屏幕任意区域：立即重播

#### 2. 输入逻辑
- 自动弹出键盘
- 禁用自动纠错
- 空格触发提交（推荐）

#### 3. 自动流（可打断）

正确：
- 绿色反馈
- +XP 动画
- 1秒后进入下一题
- 点击立即跳过等待

错误：
- 红色反馈
- 显示正确答案
- 点击立即进入下一题
- 或2秒自动进入

---

### 4. 备选输入模式（降低难度）

字母拼装：

```
a   p   p   l   e
```

点击组成单词

---

### 5. 状态机（简化版）

INIT → PLAYING → INPUT → CHECK → FEEDBACK → NEXT

支持中断：PAUSE / RESUME

---

## 4.3 结果页

```
🎉 完成

正确率 80%

🔥 streak +1
XP +120

[再来一局]
[错题复习]
```

---

## 4.4 中断恢复

- 自动保存当前进度
- 再次进入提示：
  「继续上次学习」

---

# 五、核心功能设计

## 5.1 词库系统（重点补全）

### 分级
- 初级（中考/基础）
- 中级（四级）
- 高级（六级/雅思）

### 来源
- 考试词库
- 用户自定义

---

## 5.2 错题系统（引入记忆曲线）

规则：
- 错误 → 进入错题本
- 复习间隔：1天 / 3天 / 7天
- 连续正确3次移除

---

## 5.3 节奏自适应

系统根据：
- 输入速度
- 错误率

动态调整：
- 自动跳题时间
- 重播频率

---

# 七、数据指标

## 学习效果

- 复习正确率

# 八、异常与边界处理

- 音频加载失败 → fallback
- 网络断开 → 本地缓存
- 用户切后台 → 自动暂停

# 十、总结

本版本重点不是功能堆叠，而是：

- 极快开始
- 单手操作
- 可控节奏

目标：
让用户可以“随时打开，刷一局，再回来”。
