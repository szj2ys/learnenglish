## 1. 产品概述

### 1.1 产品定位

面向成人职场人士的沉浸式英语学习微信小程序，基于科学的语言习得理论（Krashen可理解输入假说、间隔重复原理、情感过滤假说），通过角色扮演+闯关机制，在真实职场语境中掌握实用英语。

**核心价值**:
- 不是背单词，是建立「英语神经模块库」
- 基于科学的学习路径（30天启动→90天加速→长期精通）
- 零挫败感设计，所有反馈都是正向的
- 游戏化服务于学习效果，而非单纯娱乐

### 1.2 目标用户

| 维度 | 描述 |
|------|------|
| 年龄 | 22-35岁职场人士 |
| 痛点 | 英语忘得差不多，工作中遇到英文场景就焦虑；想学但没有系统方法 |
| 动机 | 升职加薪、跳槽外企、出国出差、不再害怕英文沟通 |
| 习惯 | 通勤/午休/睡前用手机，能接受碎片化学习（15-30分钟）|
| 英语水平 | 初中级（有一定基础，但多年未用）|

### 1.3 产品名称

**主推名称**: 英语神经城市 / NeuroCity English  
**备选名称**: 模块探险家 / Chunk Explorer

## 2. 核心理念与科学依据

### 2.1 语言习得科学原理

#### 2.1.1 Krashen可理解输入假说（i+1）
- **原理**: 语言习得发生在理解略高于当前水平的输入时
- **产品实现**: 内容分级系统，用户标记理解度（50%/70%/90%），系统推荐i+1难度内容

#### 2.1.2 间隔重复原理
- **原理**: 在遗忘临界点前复习，效率最高
- **产品实现**: 模块建筑升级系统（地基→框架→封顶→地标），基于SM-2算法安排复习

#### 2.1.3 情感过滤假说
- **原理**: 焦虑、压力会降低语言习得效率
- **产品实现**: 零挫败感设计，无时间限制，无失败惩罚，答错=发现薄弱点

#### 2.1.4 模块理论（Lexical Approach）
- **原理**: 语言以预制模块（chunk）形式存储，而非单词+语法规则
- **产品实现**: 核心收集单位是「表达模块」（如"I was wondering if..."），而非孤立单词

### 2.2 游戏化设计原则

| 原则 | 说明 |
|------|------|
| **正向激励** | 所有反馈都是奖励，没有惩罚机制 |
| **进度可视化** | 大脑城市地图，清晰看见神经网络的构建 |
| **即时反馈** | 每个学习动作都有反馈（收集模块、升级建筑、解锁内容）|
| **自主控制** | 用户可选择难度、主题、学习节奏 |
| **社交支持** | 学习小组、语伴匹配，减少孤独感 |

## 3. 世界观与核心玩法

### 3.1 世界观设定

你是一个「神经建筑师」，任务是帮助大脑构建「英语神经城市」。

**隐喻体系**:
- 大脑是一片待开发的土地
- 每个英语模块（词汇、句型、表达）是一座建筑
- 重复使用会让建筑升级（小屋→高楼→地标）
- 不同区域对应不同功能（听、说、读、写）
- 目标：30天建起城市框架，90天成为繁华都市

### 3.2 三阶段学习计划（游戏化版）

#### 阶段一：神经预热（第1-7天）

**科学目标**: 降低过滤机制，建立基础语音神经通路

**游戏化设计**:

| 科学要求 | 游戏实现 | 游戏元素 |
|---------|---------|---------|
| 每天20分钟儿童动画 | 「动画时间」系统 | 每天解锁一集精选动画，看完获得「语音碎片」|
| 收集10个最常用表达 | 「基础模块收集」 | 动画核心表达自动提取为卡片 |
| 录制自我介绍 | 「时光机」 | 录制音频，7天后对比第1天和第7天变化 |

**核心机制**:
- **温暖起步**: 第1天只要求5分钟，逐步增加到20分钟
- **零压力**: 不看字幕不考核，只看就有奖励
- **神经激活条**: 每天学习后，大脑的"英语区域"亮起
- **连续登录**: 欢迎回来奖励，中断无惩罚

**第7天里程碑**:
- 获得「建筑师资格证（初级）」
- 解锁第一阶段大脑城市全景
- 可对比Day1和Day7的自我介绍录音

#### 阶段二：模式识别（第8-21天）

**科学目标**: 大量可理解输入，建立模块库

**游戏化设计**:

| 科学要求 | 游戏实现 | 游戏元素 |
|---------|---------|---------|
| 选择1个兴趣主题 | 「选择你的领域」 | 美食/旅行/科技/影视，解锁专属内容地图 |
| 每天45分钟可理解输入 | 「深度探索」 | 同一主题的系列内容（短视频/播客/文章）|
| 建立模块笔记本 | 「模块工坊」 | 自动收集表达，用户标记掌握状态 |

**核心机制**:
- **主题领地**: 选择后进入专属地图（如"美食街"），所有内容围绕该主题
- **理解度标记**: 每段内容后自评"懂了多少？"（50%/70%/90%）
- **模块提取**: 系统自动高亮关键表达，一键收藏到「模块库」
- **神经连接**: 同一模块出现3次，自动建立"神经通路"（金色连线效果）

**第21天里程碑**:
- 获得「模式识别者」徽章
- 主题地图探索度达到50%
- 建立首个50模块的核心库

#### 阶段三：初步输出（第22-30天）

**科学目标**: 从输入转向输出，激活表达神经

**游戏化设计**:

| 科学要求 | 游戏实现 | 游戏元素 |
|---------|---------|---------|
| 每天15分钟自言自语 | 「独白时刻」 | AI给出话题，用户录音1分钟，无评判 |
| 每周2次语言交换 | 「语伴匹配」 | 匹配水平相当的学伴，30分钟语音对话 |
| 录制短视频 | 「成果展示」 | 用学过的模块录制1分钟视频，获得里程碑徽章 |

**核心机制**:
- **独白挑战**: AI每天提供话题（"描述你今天的早餐"），录音即可，无对错
- **时光对比**: 可听第1天、第15天、第30天的发音对比
- **语伴系统**: 匹配同主题兴趣的学伴，降低对话焦虑
- **安全环境**: 语伴聊天内容不公开，降低社交压力

**第30天里程碑**:
- 获得「建筑师证书」
- 大脑城市30天全景图生成
- 解锁「30天启动计划」成就墙

### 3.3 90天加速计划：核心模块库建设

**科学目标**: 构建1000+模块的核心库，从流利到精通

#### 3.3.1 模块收集系统

**模块定义**:
一个模块是一个完整的、可独立使用的表达单元：
- 词组："by the way", "in terms of"
- 句型："I was wondering if you could..."
- 社交公式："Nice to meet you. How do you know [person]?"

**模块卡片**:
```
┌─────────────────────────────┐
│  [▶️ 播放音频]               │
│                             │
│  "I was wondering if        │
│   you could help me with..."│
│                             │
│  📍 场景: 礼貌请求           │
│  🏗️ 熟练度: ⭐⭐⭐☆☆         │
│                             │
│  💡 变体:                   │
│  "I was wondering if        │
│   it would be possible..."   │
│                             │
│  [已掌握] [需复习]           │
└─────────────────────────────┘
```

#### 3.3.2 神经建筑升级系统（间隔重复）

基于SM-2算法，每个模块有4个等级：

| 等级 | 状态 | 视觉表现 | 复习间隔 |
|------|------|---------|---------|
| L0 | 新学 | 打地基（灰色）| 1天后 |
| L1 | 初学 | 建框架（蓝色）| 3天后 |
| L2 | 熟练 | 封顶（绿色）| 7天后 |
| L3 | 精通 | 地标建筑（金色发光）| 14-30天后 |

**复习提醒**:
- 模块需要复习时，建筑闪烁提醒
- 完成复习，建筑升级并有特效
- 错过复习，建筑变暗但不降级（无惩罚）

#### 3.3.3 每日任务系统

**输入任务**（每日2小时）:
- 听力探索：60分钟（分4个15分钟回合）
- 阅读探索：60分钟（分4个15分钟回合）

**输出任务**（每日45分钟）:
- 跟读训练：15分钟（影子跟读）
- 复述训练：15分钟（用自己的话讲）
- 创造训练：15分钟（用当天模块造句）

**游戏化**:
- 每个回合是一个「探索订单」，完成获得「建材」
- 建材用于扩建大脑城市
- 连续完成任务有加成奖励

#### 3.3.4 内容配比算法

系统自动配比学习材料：
- 60% 兴趣内容（保持动力）
- 30% 生活场景（实用需求）
- 10% 专业内容（工作需要）

### 3.4 长期维持策略（90天+）

#### 3.4.1 神经巩固系统

| 策略 | 游戏实现 |
|------|---------|
| 间隔重复 | 建筑升级系统，自动安排复习 |
| 情境迁移 | 「多面手」成就：在不同场景使用同一模块 |
| 深度加工 | 「沉浸者」徽章：用目标语思考、做梦、写日记 |

#### 3.4.2 文化融合系统

- **文化探索**: 每月一个文化主题（圣诞节、职场礼仪、社交文化）
- **真实连接**: 与母语者建立朋友关系，记录互动获得「友谊点」
- **社区活动**: 线上英语角、电影夜，参与获得「社交家」徽章

#### 3.4.3 元认知升级

- **季度复盘**: 每90天生成「神经城市年报」，可视化成长
- **教学相长**: 鼓励用户教新人，获得「导师」身份
- **个人语言哲学**: 引导用户写下学习目标

## 4. 情绪维护系统

语言学习的最大敌人是焦虑和自我怀疑。

### 4.1 零挫败感设计

| 场景 | 传统设计（挫败感）| 正向设计（本产品）|
|------|------------------|------------------|
| 答错题 | "回答错误！正确答案：C" | "发现薄弱点！已加入错题本，下次会提醒复习" |
| 没全对 | "只获得2星，要不要再试？" | "恭喜通关！完美探索可额外获得彩蛋" |
| 几天没学 | "连胜中断！" | "欢迎回来！你的大脑城市想念你了" |
| 进度落后 | "好友已经到第20关了" | "本周学习了5天，比上周多1天！" |

### 4.2 冥想与休息系统

- **大脑休息站**: 5-10分钟冥想音频，完成后恢复「专注能量」
- **疲劳提醒**: 连续学习30分钟，温柔提示休息
- **成长博物馆**: 自动保存所有录音、写作，按月展示进步

### 4.3 社群支持

- **建筑师公会**: 学习小组，分享挫折与成功
- **导师匹配**: 高水平用户帮助新人，双方都有奖励
- **匿名树洞**: 可以倾诉学习焦虑，获得鼓励

function calculateNextReview(module) {

  const level = Math.min(module.level, 4);
  
  return {
    nextReview: addDays(now, intervals[level]),
    newLevel: module.level + 1
  };
}

### 13.3 术语表

- **模块（Chunk）**: 预制语言单位，可直接使用的表达
- **i+1**: Krashen理论，输入难度略高于当前水平
- **情感过滤**: 焦虑压力对语言习得的阻碍
- **间隔重复**: 按遗忘曲线安排复习
- **可理解输入**: 理解内容含义的听力/阅读材料
